# Clothingconsultant

UiPath (RPA) automation workflow built around a clothing-consultant use case — structured data handling and process automation for a retail-style scenario.

## What's inside
- `Main.xaml` — the main automation workflow
- `project.json` — UiPath project definition and dependencies
- `.screenshots/` — workflow screenshots

## Skills demonstrated
Process analysis, structured workflow design in UiPath Studio, and data handling — the automation fundamentals I now apply to AI agent workflows (an agent is, at heart, a workflow that can reason).

## Run it
Open the project in UiPath Studio and run `Main.xaml`.
